# THE LAST REALM

> *Every choice leaves a mark. Every journey writes a different legend.*

A premium procedural narrative RPG built entirely in the browser. No backend,
no database, no APIs, no authentication. The entire game — procedural world
generation, branching narrative, combat, NPCs, factions, crafting, endings —
runs locally in your browser and saves to `localStorage`.

### Prerequisites

- **Node.js** 18+ (`node --version`)

```bash
